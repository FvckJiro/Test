Get key

Free access takes three steps. The key lasts until its expiry, then you repeat the checkpoint.

  1. Complete the checkpoint

    Finish the short checkpoint to unlock your key.

    Start checkpoint

  2. Copy your key

    The checkpoint ends on a page that shows your key. Copy it exactly, with no spaces.

  3. Run the script

    Paste the key into the key box when the script opens. Don't have a loader yet? Copy one from the Scripts tab.

    script_key = "YOUR-KEY"
